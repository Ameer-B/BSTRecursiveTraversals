# Binary Search Tree — Recursive Traversal (C#)

A simple Binary Search Tree implementation in C# showing how to perform recursive traversals:

- In-Order
- Pre-Order
- Post-Order

The project includes basic node insertion and prints each traversal to the console.

## How to Run
1. Clone the repo
2. Open the project in your C# IDE
3. Run the program to see traversal output

## Purpose
A small practice project to build and understand BST recursion.
